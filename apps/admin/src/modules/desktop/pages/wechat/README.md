# 微信菜单管理模块

## 📋 功能概述

这是一个完整的微信公众号菜单管理系统，提供了直观的界面来创建、编辑、删除和推送微信自定义菜单。

## ✨ 主要功能

### 🎯 菜单管理
- **创建菜单**: 支持添加一级菜单和二级菜单
- **编辑菜单**: 修改菜单名称、类型、按键值等属性
- **删除菜单**: 安全删除菜单（带确认提示）
- **推送菜单**: 一键推送菜单配置到微信服务器

### 📊 数据统计
- 总菜单数量统计
- 一级菜单/二级菜单分别统计
- 禁用菜单数量显示

### 🎨 用户体验
- **树形展示**: 清晰的层级结构显示
- **图标识别**: 每种菜单类型配有对应图标
- **实时预览**: 表单中实时预览菜单效果
- **状态指示**: 直观显示菜单启用/禁用状态
- **响应式设计**: 适配各种屏幕尺寸

## 🛠 技术实现

### 组件结构
```
wechat/
├── menu.vue                 # 主菜单管理页面
├── components/
│   └── WechatMenuForm.vue   # 菜单编辑表单组件
├── utils/
│   └── index.ts            # 类型定义和工具函数
└── README.md               # 说明文档
```

### 支持的菜单类型
1. **点击事件** (`click`) - 推送事件给开发者
2. **跳转链接** (`view`) - 直接跳转到网页
3. **扫码推送** (`scancode_push`) - 扫码后推送事件
4. **扫码等待** (`scancode_waitmsg`) - 扫码后等待消息
5. **系统拍照** (`pic_sysphoto`) - 调用系统相机
6. **拍照或相册** (`pic_photo_or_album`) - 拍照或选择相册
7. **微信相册** (`pic_weixin`) - 微信相册发图
8. **地理位置** (`location_select`) - 地理位置选择

### 使用的UI组件
- `XButton` - 按钮组件（支持图标、加载状态等）
- `XInput` - 输入框组件
- `XSelect` - 选择器组件
- `XInputNumber` - 数字输入框
- `XSwitch` - 开关组件
- `XDialog` - 对话框组件

### 集成的工具
- `vue-sonner` - 消息提示
- `xconfirm` - 确认对话框
- `@iconify/vue` - 图标组件

## 🎮 使用方法

### 基本操作
1. **添加主菜单**: 点击"添加主菜单"按钮
2. **添加子菜单**: 在一级菜单上点击"添加子菜单"
3. **编辑菜单**: 点击菜单项的"编辑"按钮
4. **删除菜单**: 点击"删除"按钮并确认
5. **推送菜单**: 点击"推送到微信"发布到微信服务器

### 表单验证
- 菜单名称：必填，最多5个字符
- 菜单类型：必填，根据类型显示不同的配置项
- 按键值/链接：根据菜单类型的要求填写
- URL验证：链接类型菜单会验证URL格式

### 预览功能
表单中提供实时预览，可以查看当前配置的菜单效果。

## 🔧 扩展说明

### 添加新的菜单类型
在 `menuTypes` 数组中添加新的类型配置：
```javascript
{
  value: 'new_type',
  label: '新类型',
  description: '新类型的描述',
  icon: 'lucide:icon-name'
}
```

### 自定义验证规则
在 `validateForm` 函数中添加新的验证逻辑。

### 样式定制
所有样式使用 Tailwind CSS，可以通过修改 class 属性来调整外观。
